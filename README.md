# 学生成绩管理系统

一个用 C++ 面向对象编程实现的学生成绩管理系统框架。

## 文件结构

```
student-grade-system/
├── Student.h           # 学生类声明
├── Student.cpp         # 学生类实现
├── GradeSystem.h       # 系统类声明
├── GradeSystem.cpp     # 系统类实现
├── main.cpp            # 主程序
└── students.txt        # 数据文件（自动生成）
```

## 编译与运行

### Linux/Mac
```bash
g++ -o grading_system main.cpp Student.cpp GradeSystem.cpp
./grading_system
```

### Windows (Visual Studio)
```bash
cl main.cpp Student.cpp GradeSystem.cpp
grading_system.exe
```

## 主要功能

1. **添加学生** - 输入学号、姓名、三科成绩
2. **删除学生** - 按学号删除
3. **查找学生** - 按学号快速查找
4. **显示所有学生** - 列出所有学生信息
5. **按平均成绩排序** - 显示学生排名
6. **按单科成绩排序** - 按数学/英语/语文排序
7. **更新成绩** - 修改学生成绩
8. **统计信息** - 显示各科平均分、最高分、最低分
9. **数据持久化** - 自动保存/加载文件

## 核心知识点

### 类设计
- `Student` 类：代表一个学生，包含学号、姓名、三科成绩
- `GradeSystem` 类：管理所有学生，提供增删改查功能

### STL 使用
- `vector<Student>` - 存储所有学生
- `map<string, int>` - 学号到索引的映射，实现 O(log n) 查找

### 文件操作
- `ifstream` - 从文件读取数据
- `ofstream` - 向文件写入数据
- 自定义格式转换方法

### 算法
- `sort()` + Lambda 表达式 - 按不同条件排序
- `max()` / `min()` - 求最值

## 扩展方向

1. **图形界面** - 使用 Qt 或 wxWidgets
2. **数据库** - 使用 SQLite 替代文件存储
3. **多用户** - 添加权限管理（管理员/教师/学生）
4. **统计分析** - 更复杂的数据分析功能
5. **导入导出** - 支持 CSV/Excel 格式

## 注意事项

- 学号必须唯一
- 成绩范围应该在 0-100 之间（可添加验证）
- 数据文件采用 CSV 格式：`学号,姓名,数学,英语,语文`
